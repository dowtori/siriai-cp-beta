## 1. 전체 레이아웃 — 정보 위계

대시보드 / 진행 흐름 / 진행상황 세 영역이 **같은 간격 · 같은 테두리**라
전부 같은 위계로 읽힌다. 뭘 먼저 봐야 할지 알 수 없다.

→ 간격을 벌리거나 하이어라키를 줘서 세 영역을 구분할 것.

## 2. 대시보드

- 시각 정보가 약하다.
- 변화 데이터 색상 표기가 나쁘다 — **총 누적 조회수에만** 있고 나머지는 변화 암시가 없다.
- 변화량 텍스트를 **훨씬 크게**, **알약에 넣어** 눈에 띄게.
- "10~20% 늘리지 말고 **2배 정도 확** 키울 것."

## 3. 진행 흐름

- 시도는 좋았으나 UI 완성도가 낮다. **꼭지점 표현이 나쁘다.**
- 꼭지점이 **너무 크다** — 확 줄일 것.
- 웨이브가 **상하로 펼쳐지지 말고 위로만** 펼쳐지게.
- 상단 숫자 표기가 아마추어틱하다.
- **진행 흐름에 마우스오버 시 아래 '진행상황'에서 해당 인원이 하이어라키되는 인터랙션** 필요.
  (레퍼런스는 추후 전달 예정)

## 4. 인물 카드

- **'표'가 아니라 '카드'에서만** 적용.
- 카드 전면 구성 자체는 좋다.
- **'참여율' 정보는 불필요.** → **팔로워 수 + '협업 횟수'** 표기.
- 카드 클릭 시 나오는 **콘텐츠 상하단이 잘린다.** 비율 맞춰 제대로 보이게.
  레이아웃이 바뀌어 상하 폭을 더 쓸 수 있다.
