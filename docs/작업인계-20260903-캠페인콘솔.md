## 1. 이미 되어 있는 것

단일 HTML 파일 하나다. Tailwind play CDN + Google Fonts만 외부에서 불러온다.
`build.mjs` 가 이 파일을 읽어 `dist/index.html` 을 만들고, main 에 push 하면 Vercel 이 자동 배포한다.

**이 화면은 단계를 넘나드는 곳이 아니다.** 캠페인이 "진행" 중인 한 시점에 담당자가 서 있는
실제 운영 화면이고, 시간축은 좌측 레일이 맡는다.

| 기능 | 상태 |
| --- | --- |
| 좌측 캠페인 레일 | 진행 중 1건 + 지난 캠페인 3건. 지난 건은 회색으로 죽이고 `정산 완료` / `종료` 배지만 남긴다. 누르면 실제 화면에서 무엇이 열리는지 안내한다 |
| 진행 시점 고정 | 선정 5명 중 3명 업로드 완료 · 2명 예정. 크리에이터마다 `up` 불리언을 갖는다 (인덱스로 유추하지 않는다) |
| 선정 버튼 | 체크박스 아님. 누르면 **행 전체가 연녹색**(`tr.on`)이 되고 왼쪽에 녹색 바가 선다. KPI·툴바·토스트가 함께 따라간다 |
| 전체 열 노출 | 14개 열을 처음부터 다 보여준다. 열 설정은 `후보 판단` · `진행` · `결과물` · `성과` 로 묶는다 |
| 열 순서 드래그 | 머리글을 끌어 재배치. `선정` · `크리에이터` 는 `draggable` 이 없어 고정이고 가로 스크롤에도 왼쪽에 붙는다 |
| 고정 열 정렬 | 폭을 `--c1` · `--c2` CSS 변수 하나로 묶어 sticky 오프셋과 항상 일치시킨다 (이음새 0px) |
| 스크롤 | 기본 바를 쓰지 않는다. 투명 테두리 + `background-clip:content-box` 로 안쪽에 뜬 알약이고, 호버 단계마다 짙어진다. 좌우 끝에 그라데이션을 걸어 더 볼 게 남았는지 보인다 |
| 진입 안내 | 둘러보기 화면임을 카드 하나로 먼저 알린다. 닫아도 헤더에 `둘러보기 화면` 칩이 남고 `안내 다시 보기` 로 부른다 |
| 하단 독 | `문의하기` + `∨`. 내리면 아래로 사라지고 `문의하기 열기` 알약만 남아 화면에 집중할 수 있다 |
| 미지원 동작 | UI 를 지우지 않는다. 누르면 `na()` 가 "둘러보기에서는 동작하지 않습니다 + 실제 화면에서는 ~됩니다" 를 띄운다 |
| 오른쪽 드로어 3종 | 캘린더 · 가이드라인 · 중간 보고서. ESC · 배경 클릭으로 닫히고 body 스크롤이 잠긴다 |
| 바텀시트 | 문의하기. 브랜드 / 연락처·이메일 두 칸 |

### 화면의 상태 모델

- 열마다 `group` 이 있고 이건 **설정 패널의 묶음 기준**일 뿐, 값 유무와 무관하다.
- 값이 있는지는 `cell()` 이 `c.sel`(선정) 과 `c.up`(업로드) 두 불리언으로 정한다.
  선정 전이면 `선정 후`, 선정했지만 업로드 전이면 `업로드 전` · `08.16 예정` 으로 떨어진다.
- 선정을 해제하면 `up` 과 `codeOn` 도 같이 내려간다. 진행 상태만 남는 유령 행을 막는다.
- 보고서·KPI 의 조회수는 **업로드 완료분만** 센다. 표와 모수가 갈리지 않게 한 것이다.
- 정렬 클래스는 `ALIGN` 맵에서 꺼낸다. `'text-' + align` 처럼 조립하면 빌드 스캐너가
  못 잡아 이식 후 표 정렬이 통째로 무너진다 — 되돌리지 말 것.
- 조사는 `josa()` 가 받침을 보고 고른다. `'리뷰 은'` 같은 게 한 번 보이면 화면이 싸구려가 된다.

## 2. 다음에 할 일

### 지금 이 파일에서 바로 할 수 있는 것

`<script>` 맨 위 `CREATORS` 배열만 갈면 인원·수치가 전부 따라간다. 집계는 하드코딩이 아니고 `reduce` 로 계산한다.

```js
{ name:'전수빈', handle:'@subin_jeon', roman:'SUBIN', disc:15, fol:128000, er:6.9,
  cost:350000, due:'08.06', views:842000, likes:32400, cmts:1120, saves:8900,
  extra:['틱톡'], sel:true, collab:'ok' }
```

- `roman` · `disc` 로 파트너십 코드가 만들어진다 → `SUBIN_AD3CO15`
- `sel:true` 가 처음부터 눌려 있을 사람. 지금 앞 3명
- `collab:'talk'` 로 두면 1단계에서 `협의`, 2단계부터 `수락 대기`(깜빡임)로 나온다
- `extra` 는 추가 플랫폼 게시. 지금 3명에게 있다

## 3. 정보 노출 룰

세일즈 PRD 의 정보 노출 룰에서 나온 것이다. 화면 수치는 전부 예시값이고,
아래는 **실제 캠페인 데이터를 넣을 때** 지키는 영업 규칙이다.

- **원고료(고료)는 브랜드에 절대 안 나간다.** 지금 `cost` 열은 **제안비용**이다. 열 이름을 `고료`·`정산`으로 바꾸지 말 것
- **성함·연락처·주소지·송장번호 열을 만들지 않는다.** 주소는 선정 후에만 오픈되는 프로세스다
- **매출·순이익·마진율을 넣지 않는다**
- **`가드닝`·`보충`·`증가분`·`주문` 이라는 단어를 화면에 쓰지 않는다.** 클라이언트는 우리가 직접 집행하는 것으로 안다
- **미러링/추가 게시는 보장으로 쓰지 않는다.** 인플루언서 선택 영역이라 `전원 미러링` 같은 표현은 금지
- **파트너십 코드를 `무료`로 단정하지 않는다.** 승인된 표현은 `무료 우선 · 최대 5만원`

### 이미 결정된 것 — 다시 묻지 말 것 (2026-09-03, 준용)

- **브랜드 실명 `오드타입` 은 그대로 간다.** 실재 거래처이고 대외 공개 승인이 끝났다. 배포되어 있다.
- **크리에이터 실사진·핸들을 그대로 쓴다.** 인스타 핸들과 프로필 사진은 공개 정보이고,
  노출은 크리에이터에게 불리한 게 아니라 유리한 쪽이다. 별도 동의 절차를 두지 않는다.
- **수치는 예시값으로 간다.** 화면에 `오드타입` 이 적혀 있다고 그 값이 실제 8월 실적인 것은 아니다.
  이건 제품 데모지 실적 보고가 아니다.

위 세 가지를 리스크로 다시 꺼내지 말 것. 결정은 끝났다.

## 5. 기술 메모

Artifact CSP 제약은 끝났다. 지금은 Vercel 정적 배포다.

- **실사진이 된다.** 지금 크리에이터 썸네일은 수집분을 data URI 로 넣은 것이다.
  `PICS` 배열만 갈면 교체되고, 비우면 이니셜 SVG 아바타로 자동 폴백된다.
- **SIRIAI 심볼**은 어드민의 `public/symbol-dark.png` 를 base64 마스크로 넣었다.
  `background:currentColor` 라 어느 색으로도 쓸 수 있다.
- **폰트는 Google Fonts 의 Noto Sans KR + Arimo.** 어드민으로 옮기면 Pretendard 로 바꾼다.
  그때 `.won` 클래스는 **지워야 한다** — Arimo 에 원화 기호가 없어서 넣은 우회이고,
  Pretendard 환경에서는 오히려 방해가 된다.
- **다운로드·전송은 `na()` 안내로 처리한다.** 둘러보기 화면이라 의도한 것이다. 복사는 실제로 동작한다.
- **세로 720px 이하 또는 가로 1080px 이하**에서 한 화면 고정을 포기하고 페이지를 흐르게 둔다.
  이 분기에서 flex 높이 계산을 걷어내지 않으면 리스트 높이가 0이 된다 — 미디어쿼리를 건드릴 때 주의.
  1080px 이하에서는 좌측 레일이 드로어로 바뀐다.
