## 0. 한 문단

콜드메일 본문이 세 가지를 증명한다 — **고감도**(포트폴리오) · **쉬운 프로세스**(이 화면) · **저렴함**(미팅).
이 시안은 두 번째 자리에 들어갈 링크다. 리드(아직 거래 없는 브랜드)가 열어서 5초 안에
"얘네랑 하면 편하겠다"고 느끼게 만드는 것이 유일한 목표다. 제안서가 아니라 **실제로 굴러가는 운영 화면**을 보여준다.

핵심 장치는 **한 페이지에서 손으로 굴러가는 3단계**다. 탭 전환이 아니라, 위쪽(제목·트랙·KPI)은 그대로 있고
사용자가 하단 CTA를 누르면 아래 리스트가 바뀐다. 선정 → 진행 → 완료.

## 1. 이미 되어 있는 것

단일 HTML 파일 하나다. Tailwind play CDN + Google Fonts만 외부에서 불러온다. 빌드·서버 없음.

| 기능 | 상태 |
| --- | --- |
| 3단계 진행 (선정 / 진행 / 완료·사후) | 하단 CTA 또는 상단 트랙 클릭으로 이동. 2·3단계는 선정된 사람만 나온다 |
| 선정 버튼 | 체크박스 아님. 후보 8명 중 **앞 3명이 눌린 상태로 시작**하고, 안 눌린 것은 첫 클릭 전까지 인디고 링이 깜빡인다 |
| 단계별 열 프리셋 | 단계를 바꾸면 보여줄 열이 갈린다 (`PRESET` 상수) |
| 열 표시 설정 | 톱니 버튼 → 14개 열을 단계별로 묶어 체크. `단계 기본값` 으로 되돌린다 |
| 열 순서 드래그 | 머리글을 끌어 재배치. `선정` · `크리에이터` 는 `draggable` 자체가 없어 고정이고 가로 스크롤에도 왼쪽에 붙는다 |
| 파트너십 코드 (마이너스 옵션) | 완료 파트에만 기본 노출. 설정에서 켜면 1단계에서 행별 `발급` / `제외` 를 고를 수 있고 상단 집계가 즉시 따라간다 |
| 오른쪽 드로어 4종 | 캘린더 · 가이드라인 · 보고서 · **추가 옵션**(`dw-more`). 오른쪽에서 왼쪽으로 슬라이드. 추가 옵션은 툴바 `+ 추가 옵션` 버튼으로 열리고, 3장의 승인 문구(`무료 우선 · 최대 5만원`)가 여기 들어 있다 |
| 바텀시트 | 커피챗 신청. 아래에서 위로. 브랜드 / 연락처·이메일 두 칸만 |
| 사후처리 | 3단계에서만 표 아래에 띠로 나온다 (원본 일괄 · 2차 활용 신청 · 보고서 · CSV) |
| 스크롤 | **페이지는 스크롤되지 않는다.** 리스트 안에서만 세로·가로 스크롤. 표 머리글은 붙어 있다 |

### 화면의 상태 모델 — 이걸 모르면 열이 왜 비는지 모른다

- 열마다 `phase`(1·2·3)가 있고, 이건 **설정 패널의 묶음 기준**이다.
- 셀이 값을 갖는지는 `phase` 가 아니라 **단계별 데이터 유무**로 정한다. `cell()` 안에서 단계를 보고 갈린다.
- 2단계는 "선정 인원 중 콘텐츠 한두 개만 올라온 상황"이다 — `UPLOADED_IN_STEP2 = 2`.
  업로드된 사람만 조회수·추가 플랫폼·콘텐츠 링크에 값이 있고 나머지는 `08.21 예정` + 빈 칸이다.
- 1단계의 `공동작업자` · `2차활용` 은 실제 상태가 아니라 **가능 여부**(`가능` / `협의`)다.
  선정 판단에 쓰는 값이라 그렇게 뒀고, 2·3단계에서 `승인` / `수락 대기` / `자사몰 · 광고` 로 바뀐다.
- 지난 단계에서 확정된 열은 회색으로 죽는다(`quiet`). 다음 단계 열은 빈 칸 + 옅은 배경이다.

## 2. 다음에 할 일

### 지금 이 파일에서 바로 할 수 있는 것

`<script>` 맨 위 `CREATORS` 배열만 갈면 인원·수치가 전부 따라간다. 집계는 하드코딩이 아니고 `reduce` 로 계산한다.

```js
{ name:'전수빈', handle:'@subin_jeon', roman:'SUBIN', disc:15, fol:128000, er:6.9,
  cost:350000, due:'08.06', views:842000, likes:32400, cmts:1120, saves:8900,
  extra:['틱톡'], sel:true, collab:'ok' }
```

- `roman` · `disc` 로 파트너십 코드가 만들어진다 → `SUBIN_AD3CO15`
- `sel:true` 가 처음부터 눌려 있을 사람. 지금 앞 3명
- `collab:'talk'` 로 두면 1단계에서 `협의`, 2단계부터 `수락 대기`(깜빡임)로 나온다
- `extra` 는 추가 플랫폼 게시. 지금 3명에게 있다

## 3. ⚠️ 실데이터로 바꿀 때 지킬 것

지금 12개 값 전부 가상이라 안전하다. 실제 캠페인으로 바꾸는 순간 아래가 걸린다.
`docs/보안` · 세일즈 PRD의 정보 노출 룰에서 나온 것이고, 어기면 대외 링크로 새 나간다.

- **원고료(고료)는 브랜드에 절대 안 나간다.** 지금 `cost` 열은 **제안비용**이다. 열 이름을 `고료`·`정산`으로 바꾸지 말 것
- **성함·연락처·주소지·송장번호 열을 만들지 않는다.** 주소는 선정 후에만 오픈되는 프로세스다
- **매출·순이익·마진율을 넣지 않는다**
- **`가드닝`·`보충`·`증가분`·`주문` 이라는 단어를 화면에 쓰지 않는다.** 클라이언트는 우리가 직접 집행하는 것으로 안다
- **인플루언서 얼굴 사진**은 지금 이니셜 아바타다. 실사진을 넣으려면 본인 게재 동의가 필요하다
- **브랜드 실명**(`오드타입`)이 제목에 박혀 있다. 실재 클라이언트이므로 **대외 발송 전 준용 승인 필요**
- **미러링/추가 게시는 보장으로 쓰지 않는다.** 인플루언서 선택 영역이라 `전원 미러링` 같은 표현은 금지
- **파트너십 코드를 `무료`로 단정하지 않는다.** 승인된 표현은 `무료 우선 · 최대 5만원`

내용·수치·전략은 준용이 정한다. 이어받는 사람이 임의로 채우지 말 것.

| 항목 | 무엇을 정해야 하나 |
| --- | --- |
| 브랜드 실명 | 오드타입 그대로 갈지, 가상 브랜드명으로 바꿀지 |
| 데이터 진위 | 실제 완료 캠페인으로 교체할지 (교체하면 인플루언서 게재 동의 필요) |
| 단가 노출 | 지금 15만~35만이 행별로 다 보인다. 조회수와 같은 행이라 나눗셈으로 뷰당 단가가 역산된다 — 준용이 상관없다고 판단해 그대로 뒀다 |
| 링크 목적지 | `보고서` · `가이드라인` 드로어의 PDF, 커피챗 폼 전송처가 전부 비어 있다 (토스트만 뜬다) |
| 인원 규모 | 후보 8명 기준으로 높이를 잡았다. 20명 이상이면 표시 상한이 필요하다 |

## 5. 기술 제약 — 한 번씩 걸린 것

- **Pretendard를 쓰지 못했다.** `cdn.jsdelivr.net` 의 Pretendard 스타일시트는 Claude Artifact CSP가
  **조용히 차단한다**(에러도 안 뜬다). 그대로 두면 윈도우에서 맑은고딕으로 떨어지므로 Google Fonts의
  `Noto Sans KR` 로 폴백을 걸어 뒀다. **어드민(Vercel)으로 옮기면 원래대로 Pretendard를 쓰면 된다.**
- **외부 이미지가 CSP에 막힌다.** 아티팩트로 볼 때는 인스타 프로필 사진을 URL로 못 불러온다.
  그래서 인라인 SVG 이니셜 아바타로 갔다. 어드민에서는 실사진이 된다.
- **원화 기호(₩)를 Arimo가 갖고 있지 않다.** 전각 폴백이 걸려 두 개처럼 보였다.
  `.won` 클래스로 국문 폰트를 강제해 뒀다 — 지우지 말 것.
- **다운로드·복사는 토스트만 뜬다.** 아티팩트 샌드박스가 페이지가 시작하는 다운로드를 막는다. 목업이므로 의도한 것이다.
- **모바일(880px 이하)에서만 페이지 스크롤을 허용한다.** 한 화면에 담을 수 없어서다.
  이 분기에서 flex 높이 계산을 걷어내지 않으면 리스트 높이가 0이 된다 — 미디어쿼리를 건드릴 때 주의.
